## Usage

``` r
filter_adam_db(dat, pop_var, pop_value, custom_pop_filter)
```

## Arguments

- dat:

  A data.table containing the analysis data.

- pop_var:

  Population flag variable.

- pop_value:

  A character containing the acceptance value of population flag value.

- custom_pop_filter:

  A character string containing a custom population filter.

## Value

A data.table containing the filtered analysis data.
